# HTML Event Website — Web Development Practice

**Status: Learning project**

A collection of beginner HTML, CSS, and JavaScript exercises from web development training.

## Repository Structure

- `index.html` — introductory HTML practice page
- `project/index.html` — image and HTML practice
- `project/event.html` — basic registration-form practice
- `project/event2.html` — Meesho-themed page exercise
- `project/audio.html` — audio element practice
- `project/video.html` — video element practice
- `project/style.css` — CSS practice
- `project/script.js` — JavaScript DOM practice

## How to Explore

Open individual HTML files in a web browser. The exercises are independent examples rather than a single integrated production website.

## Known Limitations

- Some exercises contain incomplete markup or JavaScript.
- Some images and media references point to local files or unavailable resources.
- The Meesho-themed exercise references an image asset that has not yet been uploaded to this repository.

These files are preserved as learning exercises and will be improved as I continue practicing web development.
